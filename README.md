# Inventario de biblioteca

Aplicación de consola en Java para gestionar el inventario de una biblioteca.

## Funciones
- Agregar un libro (título, autor, año de publicación y precio)
- Mostrar todos los libros
- Buscar un libro por título

## Conceptos utilizados
- Programación orientada a objetos (clase `Libro`)
- `ArrayList`
- Bucle `do-while` para el menú
- Validación de datos de entrada

## Cómo ejecutarlo
Compila y ejecuta la clase `TareaLibreria` (paquete `com.saravm`).
